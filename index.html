阿里云快递接口（管理员，三家商品共用同一个 AppCode）
三家商品在云市场共用一个 AppCode（同一个账号）。到 market.aliyun.com 搜「快递查询」订购后， 在「我的服务」里就能看到 AppCode。德邦、京东、EMS、韵达都能查。

软件安装
安装到手机主屏幕
iPhone（推荐 Web Clip）：点下面按钮下载描述文件 → iPhone 弹出提示后去「设置 → 已下载的描述文件 → 安装」，主屏幕就会出现应用图标，点开全屏运行。
iPhone（备用）：Safari 打开本页 → 分享 → 添加到主屏幕。
安卓：Chrome / 三星浏览器 菜单 → 添加到主屏幕（不装 APK 也能用，内容永远最新）。
装完没看到图标？图标会排在最后一屏（往左翻到底）；如果之前装过旧版，先到「设置 → 通用 → VPN与设备管理」把旧的「美妆回收统计」删掉，再重新装一次。
免登录版会生成一把长期密钥写进描述文件，图标点开直接进账本，不再跳登录页；点「退出登录」也不会失效（密钥只在重新生成图标时才作废）。只装在自己手机上。
安卓手机下载后点开安装，提示「未知来源」时选择允许，桌面出现「美妆回收」图标。之前装过旧版的，请先在桌面卸载再装（签名换了不能覆盖升级，卸载不影响云端数据）。
